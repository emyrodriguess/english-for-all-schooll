# Sistema interno — documentação

- `PRD.md`: escopo funcional e critérios de aceite do MVP.
- `DECISIONS.md`: decisões que refinam e, quando necessário, prevalecem sobre exemplos do PRD.
- `IMPLEMENTATION.md`: plano executado, entregáveis e pendências externas.
- `DESIGN.md`: referência visual aprovada e regras de aplicação.
- `SETUP.md`: preparação dos ambientes local e remoto.

Ordem de leitura: PRD, decisões, implementação, design e setup. O fluxo vertical `Login → Aluno → Responsável → Contrato → Cobranças → Pagamento` e os módulos de Agenda, Turmas, Financeiro, Planner e Importações estão implementados.
